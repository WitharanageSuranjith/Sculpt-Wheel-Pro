How it works

Install. Activate. Start sculpting.

Three clear steps take Sculpt-Wheel from a downloaded ZIP to a licensed, Blender-native brush workflow.

01

Install the add-on.

In Blender 4.3 or newer, open Edit > Preferences > Get Extensions. Choose Install from Disk, select the Sculpt-Wheel ZIP without extracting it, then enable the add-on.

Blender PreferencesGet Extensions

02

Request your activation key.

Copy the Machine Code from Sculpt-Wheel's preferences, then send it with your Superhive receipt or order ID through the Superhive Inbox.
