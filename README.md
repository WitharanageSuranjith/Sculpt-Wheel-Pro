# Sculpt-Wheel 1.0.010 — Prototype 2

Sculpt-Wheel is a configurable sculpt-brush radial wheel for Blender 4.3 and
newer, including Blender 5.x.

Version 1.0.010 includes the Wheel Menu Editor and persistent presets.

## Install

1. In Blender, open **Edit > Preferences > Get Extensions**.
2. Open the menu and choose **Install from Disk**.
3. Select the Prototype-2 ZIP; do not extract it first.
4. Enable **Sculpt-Wheel**.

## Activate

Open Sculpt-Wheel's Add-on Preferences or Sculpt Mode N-panel and copy the
displayed Machine Code. Send it with the Superhive receipt/order ID through the
Superhive Inbox. Paste the returned key into **Activation Key** and press
**Activate**.

Activation verification is fully offline. Sculpt-Wheel makes no network
requests and contains no analytics or telemetry.

## Use

Enter Sculpt Mode and press **Spacebar** to open the radial wheel.

- Click a brush slot to activate it.
- Use grouped slots to open brush sub-menus.
- Configure appearance and wheel behavior in the N-panel or Add-on Preferences.
- Use **Wheel Menu Editor** for full preset and brush-slot editing.
